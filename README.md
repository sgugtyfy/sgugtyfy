# 学研题库 · 信息检索与科研写作

根据用户提供的两张 CSDN、知乎长截图整理的静态题库。原小游戏已替换。

- 266 条题目记录（含截图开头的 1 条不完整片段），按 11 个专题组织；所有题目默认一次性展示，无分页、无限滚动或远程加载。
- 搜索题干、选项和备注，按单选、多选、判断、填空筛选。
- 默认显示原图答案，可整体或逐题隐藏；缺失的答案明确标记，不另行推断。
- 每题均可查看上传截图中对应的原始区域；重复题保留多个来源供核对。
- 支持手机、键盘操作和浏览器打印。不使用第三方字体、分析服务或外部资源，无账号及后台依赖。

## 数据说明

`questions.js` 为题库数据，`sources/` 为对应截图裁片。截图重复部分按专题与原题号合并；同义重复题也作了合并。原题号仅用于来源对照，网页显示连续编号。课程章节、视频时间、教师姓名等导出杂项不作为选项保留。截图未提供内容的题号不创建虚构题目。

所有答案照录截图，未做知识正确性校订。知乎截图开头存在截断片段；部分原文未完句和异常答案予以保留并可通过原图核对。正文中明显的文字识别错误已按截图校正。

## 本地查看

直接用浏览器打开 `index.html`，无需安装依赖。也可用任意静态文件服务器运行。

## Northflank 部署

保留原仓库根目录的 Dockerfile，使用 `nginx:alpine`，HTTP 端口为 **80**。沿用 Northflank 现有 GitHub 仓库及分支绑定；将这些变更提交并推送至绑定分支后，已配置的自动部署会构建新版。

## 检查

运行 `node scripts/verify.mjs` 检查题库、选项答案及所有原图文件，并确认部署所需资源齐全。

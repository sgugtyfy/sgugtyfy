# 学研题库 · 信息检索与科技写作

题库已整体改用 [Oldmemory1 / BIT-Information-Retrieval-and-Scientific-Writing](https://github.com/Oldmemory1/BIT-Information-Retrieval-and-Scientific-Writing)。原先的截图题库及 360 张截图裁片已移除。

完整导入仓库的 12 份章节习题，共 **475 题**，包含单选、多选、判断、填空和简答题。所有题目默认在同一页展开，不分页、不无限滚动、不在浏览时远程加载题库。

支持关键词与章节搜索、五种题型筛选、章节跳转、整体或逐题隐藏答案、来源原文对照、原始 TXT 下载和打印。电脑与手机均可使用，无账号或后台依赖。

## 来源与整理原则

`sources/` 保存本次下载的 12 份完整原始 TXT；`manifest.json` 记录来源、文件 Git blob SHA、章节题数及导入日期（2026-11-02）。`questions.js` 是由原始文件生成的网页数据，每道题均保存文件名、原题号、原文及准确行号，可与 GitHub 来源核对。

- 保留原始题目、选项和答案，不混入旧截图题库，不另行推断或校订知识答案。
- 将选择题括号内的答案移到答案区，将填空答案替换为可见空格，多个空格按顺序编号。
- 简答题保留完整参考答案；题干涉及排序的选择题归为多选题，答案按原文顺序直接显示字母（如 `EADBC`），不使用箭头。
- 只合并题干、选项、题型和答案都相同的记录；本次来源的 475 条记录均保留。
- `9.4习题.txt` 的第 46 条在源文件中误标为第 56 题，与后面的第 56 题重号。网页使用独立连续编号，保留原题号并单独注明，不覆盖任何一道题。

## 本地查看与检查

直接在浏览器打开 `index.html`，无需安装依赖。也可以使用任意静态文件服务器。

```powershell
node scripts/import-bank.mjs
node scripts/verify.mjs
```

第一条命令依据已保存的原始 TXT 重新生成网页题库，不联网。第二条命令校验全部题目、原文范围、来源哈希、选项、答案和部署文件，并检查旧截图资源已移除。

## 自行推送与 Northflank 部署

沿用原仓库根目录的 Dockerfile，通过 `nginx:alpine` 提供网页，HTTP 端口为 **80**。在本地提交后自行推送到已绑定的 `main` 分支，Northflank 的自动构建与部署会更新网站。本次修改不代为推送或操作线上服务。
